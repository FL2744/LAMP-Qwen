# LAMP-Qwen
LAMP-Qwen provides editable numerical memory for a frozen language model through a native macOS application and command-line tools. The self-contained Apple Silicon app includes Qwen3.5-0.8B and its Python runtime, with chat, base-versus-memory comparisons, memory writing, slot controls, and numerical weight editing.

[Download the native macOS app and full source on Hugging Face](https://huggingface.co/will-taggart/LAMP-Qwen-v0.1). The packaged app requires macOS 26 or later.
